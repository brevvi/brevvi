## Olá, eu sou o Brevvi

Profissional de internet com mais de 30 anos de mercado e mais de 500 projetos publicados. Neste espaço compartilho com a comunidade projetos que criei em código aberto, para dividir conhecimento. Entre eles, os projetos das aulas de um curso em desenvolvimento (w.i.p.).
